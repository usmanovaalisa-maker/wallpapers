# assets

Сюда кладётся содержимое папки `assets/` из архива `kristina-wb-visuals.zip`
— как есть, без переделки изображений.

```
assets/
├── slides/
│   ├── 01.jpg  01.png
│   ├── 02.jpg  02.png
│   ├── 03.jpg  03.png
│   ├── 04.jpg  04.png
│   ├── 05.jpg  05.png
│   └── 06.jpg  06.png
└── blocks/
    ├── 07-reviews.jpg  07-reviews.png
    └── 08-finale.jpg   08-finale.png
```

Страница подставляет `.jpg` ради скорости загрузки, а `.png` остаётся в
проекте как качественная версия и используется автоматически, если `.jpg`
рядом нет.

Слайды — в пропорции 3:4 и показываются целиком, без обрезки. Если имена
файлов в архиве отличаются, достаточно поправить атрибуты `data-src`
в `index.html` — больше ничего менять не нужно.
