# Ежедневная задача Claude на своём компьютере

Раньше эту работу делали два задания в облачной сессии Claude Code. Теперь хватит одной
запланированной задачи в Claude Desktop на вашем Mac — облачные кредиты не тратятся.
Ничего, кроме Git, устанавливать не нужно.

Как это работает: каждый день в 11:30 задача пишет фразы на завтра и делает push в GitHub.
Сами рассылки в чаты «Доброплан 2026 _ Чат руководителей» и «НГ 2026-2027» уходят в 10:00 по расписанию
GitHub Actions, а если GitHub опоздал — их запускает этот push (повторно в тот же день не отправляется).
Ключи TrueStats и Битрикс24 остаются в секретах GitHub — на компьютер их переносить не нужно.

## Шаг 1. Проект на компьютере (уже сделано)

```
cd ~/Documents
git clone https://github.com/usmanovaalisa-maker/wallpapers
```

## Шаг 2. Разрешите компьютеру отправлять изменения в GitHub (один раз)

1. В браузере откройте https://github.com/settings/personal-access-tokens/new
2. Token name: `Дари Сейчас — Mac`. Expiration: `366 days` (или «No expiration»).
3. Repository access: **Only select repositories** → выберите `wallpapers`.
4. Permissions → Repository permissions → **Contents: Read and write**.
5. Нажмите **Generate token** и скопируйте токен (он начинается с `github_pat_`). Никому его не пересылайте.
6. В Терминале:
   ```
   cd ~/Documents/wallpapers
   git config credential.helper osxkeychain
   git push
   ```
   На вопрос **Username** введите `usmanovaalisa-maker`, на **Password** — вставьте токен
   (символы при вводе не видны — это нормально) и нажмите Enter. Ответ `Everything up-to-date` —
   значит, всё получилось: Mac запомнил токен в Связке ключей и больше спрашивать не будет.

## Шаг 3. Создайте задачу в Claude Desktop

1. Откройте Claude Desktop → вкладка **Code** → выберите папку `Документы/wallpapers`.
2. Отправьте в чат:
   > Открой файл docs/local-claude-tasks.md и создай запланированную задачу «Рассылки и фразы — Дари Сейчас»: каждый день в 11:30 по часовому поясу Самары, текст — из раздела «Текст задачи».
3. Если Claude попросит разрешения, подтвердите.

## Текст задачи (каждый день в 11:30)

С 29.10.2026 остаётся только новогодняя рассылка в чат «НГ 2026-2027». Рассылка в «Доброплан» и фразы для
подписчиков (wishes/fans.json) отключены — команде и подписчикам фразы больше не пишем.

```
Сначала отметь запуск, потом напиши свежие тексты на ЗАВТРАШНИЙ день для новогодней рассылки бренда «Дари Сейчас» (подарки и чай). Работай в папке репозитория wallpapers (GitHub usmanovaalisa-maker/wallpapers, ветка main, владелец разрешил пушить прямо в main). Сегодняшний push запустит сегодняшнюю рассылку: GitHub Actions подтянет итоги прошедшего дня из TrueStats (только группа артикулов «НГ26-27/Новый год 2027» + итоги с начала сезона), выберет подходящий вариант текста и отправит в Битрикс24, в чат «НГ 2026-2027». Формат сообщения: основной текст → строка с реальными цифрами → поддерживающая фраза с пожеланием (она же на картинке). Фразы для подписчиков (wishes/fans.json) и для команды (wishes/team.json, daily) больше НЕ пишем — эти рассылки отключены.

Шаги:
1. `git fetch origin main && git checkout main && git reset --hard origin/main` (локальных изменений быть не должно). Определи ЗАВТРАШНЮЮ дату в часовом поясе Europe/Samara (ДАТА = ГГГГ-ММ-ДД) и её день недели. Запиши в файл .github/last-local-run текущие дату и время по Самаре (одной строкой) — этот файл коммитится всегда: его push запускает сегодняшнюю рассылку.
2. Если в wishes/ng.json уже есть daily[ДАТА] или ДАТА не рабочий день (нет ключа ДАТА в calendar файла wishes/team.json) — сразу переходи к шагу 6 (закоммить только .github/last-local-run).
3. Новогодняя рассылка (wishes/ng.json): daily["ДАТА"] = ОБЪЕКТ с восемью полями. Основной текст (перед цифрами): "record" — вчера лучший день сезона; "up" — вчера новогодние продажи выросли к позавчера; "steady" — примерно как раньше; "support" — спад или данных нет (поддержка без упрёков, без упоминания спада). Фраза после цифр (она же на картинке): "reaction_record", "reaction_up", "reaction_steady", "reaction_support" — 1–2 предложения, до 150 символов: тёплая реакция на результат и пожелание на сегодня, не повторяя мысль основного текста того же исхода. Основные тексты: на «вы»/«команда»/«коллеги», 1–3 предложения, до 200 символов, цифр НЕ пиши и не выдумывай. Тема — новогодний сезон: «рекорд сезона», рост новогодних продаж, стабильный темп; образы — Дед Мороз, сани, ёлка, гирлянды, снег, подарки, мандарины, «каждый заказ — чьё-то праздничное утро». Тон бодрый, праздничный. Понедельник — настрой на неделю (цифры — только за воскресенье в сравнении с субботой); пятница — спасибо за неделю и хороших выходных; последний рабочий день месяца — итоги месяца. Никогда не касайся политики, войн, трагедий, болезней, религиозных споров, скандалов, чужих брендов и знаменитостей.
4. Неповторимость: новые тексты не должны совпадать или быть почти одинаковыми ни с одним текстом в wishes/ng.json (daily, fallback, results_reactions, включая поля внутри объектов). Проверь скриптом на Python (нормализованный текст и difflib ratio > 0.8) и замени похожие.
5. Сохрани wishes/ng.json (UTF-8, ensure_ascii=False, indent=1). Проверь json.load и что `WISH_DATE=ДАТА DRY_RUN=1 WISHES_FILE=wishes/ng.json python3 scripts/send_bitrix.py` отрабатывает без ошибок. Больше ничего не меняй (кроме .github/last-local-run).
6. Закоммить с сообщением «Новогодние тексты на ДАТА» (или «Запуск рассылки», если менялся только .github/last-local-run) и сделай `git push origin main` (при отказе — `git pull --rebase origin main` и повтори до 4 раз). Повторно в тот же день рассылка не отправится.
7. Кратко перечисли добавленные тексты.
```

## Как сверять цифры

- Цифры в чаты попадают только из TrueStats: Claude их не пишет, он готовит только тексты без цифр.
- **Данные ещё не выгрузились — рассылки нет.** TrueStats заполняет прошедший день с задержкой: сначала приходят
  заказы, а продажи и реализация остаются нулём. Если за какой-то день периода продажи и реализация = 0,
  в чат ничего не уходит. Повторные попытки — в 11:30 (push с компьютера), 12:30 и 14:00 по Самаре.
- **Контрольная копия.** После каждой отправки (и когда отправка отложена) вам лично в Битрикс24 приходит
  контрольная копия: статус, фильтр TrueStats, цифры по дням (заказы · сумма заказов · продажи · реализация · прибыль),
  по магазинам, с чем сравнивали и почему выбран уровень, и само сообщение. Сверять — с вкладкой «По дням» в TrueStats
  при том же фильтре: магазины «Дари Радость» и «Дари сейчас» для «Доброплана», группа «НГ26-27/Новый год 2027» для НГ.
- Копия приходит пользователю из переменной GitHub `BITRIX_CONTROL_ID` (или `BITRIX_DIALOG_ID`, если там ID пользователя,
  а не `chat…`). В лог GitHub цифры не пишутся — репозиторий публичный.

## Если компьютер выключен

- Фразы на завтра не напишутся — уйдут запасные тексты из календаря (ничего не сломается).
- Рассылку в этот день запустит расписание GitHub Actions (10:00), но иногда с опозданием на несколько часов.
  Повторной отправки не будет — перед отправкой проверяется, отправляли ли сегодня.
- Push раньше 10:00 рассылку не запускает (чтобы TrueStats успел обновить цифры за вчера).
