# Сюда кладутся картинки

Скопируйте в эту папку содержимое папки `assets` из архива
`kristina-wb-visuals.zip`.

Должно получиться так:

```
assets/
├── slides/      ← шесть слайдов галереи
│   ├── 01.jpg   01.png
│   ├── 02.jpg   02.png
│   ├── 03.jpg   03.png
│   ├── 04.jpg   04.png
│   ├── 05.jpg   05.png
│   └── 06.jpg   06.png
└── blocks/      ← отзывы и финальное поздравление
    ├── 07-reviews.jpg   07-reviews.png
    └── 08-finale.jpg    08-finale.png
```

Страница показывает файлы `.jpg` — они легче и открываются быстрее.
Файлы `.png` лежат рядом как качественные версии на случай будущих правок;
если какого-то `.jpg` не окажется, страница сама возьмёт `.png`.

Картинки вертикальные, в пропорции 3:4, и показываются целиком — ничего не
обрезается.
