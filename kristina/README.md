# Поздравление Кристине — как опубликовать

Страница выглядит как карточка товара на маркетплейсе, а после нажатия
«Оформить заказ» раскрывается поздравление с днём рождения.

Ниже — пять шагов. Ничего устанавливать не нужно, всё делается в браузере.

---

## Шаг 1. Скачать папку себе на компьютер

Готовый код пока лежит только на GitHub, в отдельной ветке.
На вашем компьютере его ещё нет — сначала скачайте.

1. Откройте ссылку:
   <https://github.com/usmanovaalisa-maker/wallpapers/tree/claude/laughing-galileo-9klzts>
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Распакуйте скачанный архив.

Внутри будет папка `wallpapers-claude-laughing-galileo-9klzts`, а в ней —
папка **`kristina`**. Это и есть сайт. Дальше работаем только с ней.

Остальные папки из архива (`cards`, `scripts`, `wishes` и прочие) — это ваш
старый проект, их не трогаем.

---

## Шаг 2. Положить картинки

Распакуйте архив `kristina-wb-visuals.zip` и найдите внутри папку `assets`.
Скопируйте её целиком в папку `kristina`.

Должно получиться так:

```
kristina/
├── index.html
├── styles.css
├── app.js
├── favicon.svg
├── README.md
└── assets/          ← вот эту папку вы добавляете
    ├── slides/
    └── blocks/
```

> **Важно:** папку `sources/photos` из архива копировать не нужно.
> Это исходные фотографии, они нужны только для будущих правок.

**Проверьте себя:** внутри должно лежать `kristina/assets/slides/01.jpg`.
Если после `assets` сразу идёт ещё одна папка `assets` — вы скопировали на
уровень глубже, поднимите её на шаг выше.

---

## Шаг 3. Посмотреть, что всё на месте

Откройте файл `kristina/index.html` двойным щелчком — он откроется в браузере.

Если все шесть фотографий видны — можно публиковать.

Если вместо фотографии видна серая полосатая заглушка, на ней написано имя
файла, которого не хватает. Значит, картинки лежат не там — вернитесь к шагу 2.

---

## Шаг 4. Загрузить папку на GitHub

Загружаем в основную ветку `main` — тогда публикация заработает.

1. Откройте <https://github.com/usmanovaalisa-maker/wallpapers>
   и убедитесь, что сверху слева выбрана ветка **main**.
2. Нажмите **Add file → Upload files**.
3. Перетащите папку **`kristina`** целиком в окно браузера.
   Дождитесь, пока загрузятся все файлы вместе с картинками —
   их около двух десятков, это занимает полминуты.
4. Внизу выберите **Commit directly to the `main` branch**
   и нажмите зелёную кнопку **Commit changes**.

После этого в репозитории на ветке `main` должна появиться папка `kristina`.

---

## Шаг 5. Включить публикацию

Это делается один раз.

1. В репозитории откройте вкладку **Settings** (шестерёнка сверху).
2. Слева в меню выберите **Pages**.
3. В разделе **Build and deployment**:
   - **Source** — выберите **Deploy from a branch**
   - **Branch** — выберите `main` и папку `/ (root)`
4. Нажмите **Save**.

Подождите 1–2 минуты, пока GitHub соберёт страницу.

## Что происходит на странице

1. **Галерея** сверху — шесть слайдов. На телефоне листаются пальцем,
   на компьютере — стрелками по бокам. Справа внизу видно, какой слайд
   открыт: `1 / 6`.
2. **Карточка товара** — имя, рейтинг, артикул, цена «БЕСЦЕННА».
   Кнопка «Добавить в корзину» показывает шутливое сообщение.
3. **Описание, сопутствующие товары и отзывы.**
4. **Кнопка «Оформить заказ»** внизу экрана — главная. После нажатия
   несколько секунд идёт «оформление», а потом появляется поздравление.
   Его можно закрыть крестиком и открыть снова той же кнопкой.
5. **Кнопка «Получить подарок»** под поздравлением показывает фразу
   «Подарок ждёт тебя в реальной жизни :)».

## Если что-то пошло не так

**Ссылка не открывается, ошибка 404.**
Подождите ещё пару минут — после первой настройки GitHub собирает страницу не
сразу. Если не помогло, проверьте шаг 4: в настройках Pages должна быть
выбрана ветка `main` и папка `/ (root)`.

**Страница открылась, но вместо фотографий полосатые заглушки.**
Картинки не попали на GitHub. Проверьте, что в репозитории на сайте GitHub
видна папка `kristina/assets/slides` и в ней лежат файлы.

**В настройках Pages в списке веток нет `main`, или страница пустая.**
Проверьте, что папка `kristina` лежит именно в ветке `main`. Откройте
репозиторий, переключатель веток сверху слева поставьте на `main` и
посмотрите, видна ли папка. Если её там нет — вернитесь к шагу 4.
Ветка `claude/laughing-galileo-9klzts` — черновая, публиковать из неё не нужно.

**Хочу поменять текст на странице.**
Весь текст лежит в файле `index.html` — его можно открыть в обычном Блокноте
и поправить. Текст, который нарисован прямо на фотографиях, так поменять
нельзя, для этого нужно перерисовать сами картинки.

**Хочу поменять фотографии.**
Замените файлы в `kristina/assets/` на новые с теми же именами
(`01.jpg`, `02.jpg` и так далее) и загрузите их на GitHub заново.
Фотографии должны быть вертикальными, в пропорции 3:4.
