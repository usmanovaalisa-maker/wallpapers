# Ежедневные задачи Claude на своём компьютере

Две задачи, которые раньше работали в облачной сессии Claude Code. Их можно запускать
у себя на компьютере в приложении Claude Desktop — тогда облачные кредиты не тратятся.
Задача срабатывает, только если в это время компьютер включён и Claude Desktop запущен.

## Подготовка (один раз)

1. Установите Git и склонируйте репозиторий в удобную папку:
   ```
   git clone https://github.com/usmanovaalisa-maker/wallpapers
   ```
2. Установите GitHub CLI (https://cli.github.com) и войдите: `gh auth login`
   (нужен для задачи 2 — она запускает рассылки в GitHub Actions).
3. Проверьте, что Python 3 установлен: `python3 --version`.
4. В Claude Desktop откройте папку `wallpapers` и создайте две запланированные задачи
   (Scheduled tasks) с текстами ниже. Часовой пояс — Europe/Samara.

Цифры, ключи TrueStats и Битрикс24 остаются в секретах GitHub — на компьютер их переносить не нужно:
отправка по-прежнему идёт из GitHub Actions.

## Задача 1 — «Свежие фразы на завтра», каждый день в 09:53

```
Напиши свежие фразы на ЗАВТРАШНИЙ день для бренда «Дари Сейчас» (подарки и чай): для подписчиков, для команды и для новогодней рассылки — это разные аудитории с разным тоном. Работай в папке репозитория wallpapers (GitHub usmanovaalisa-maker/wallpapers, ветка main, владелец разрешил пушить прямо в main). Завтра в 10:00 по Europe/Samara GitHub Actions подтянет итоги прошедшего дня из TrueStats, выберет подходящий вариант текста и отправит в Битрикс24: напутствие команде — в чат «Доброплан 2026 _ Чат руководителей» (итоги по магазинам «Дари Радость» и «Дари сейчас»), новогоднюю рассылку — в чат «НГ 2026-2027» (итоги только группы артикулов «НГ27_ВБ» + итоги с начала сезона). Формат сообщения: основной текст → строка с реальными цифрами → поддерживающая фраза с пожеланием (она же на картинке). Сайт https://usmanovaalisa-maker.github.io/wallpapers/ весь день показывает фразы подписчикам.

Шаги:
1. `git fetch origin main && git checkout main && git reset --hard origin/main` (локальных изменений быть не должно). Определи ЗАВТРАШНЮЮ дату в часовом поясе Europe/Samara (ДАТА = ГГГГ-ММ-ДД) и её день недели.
2. Проверь каждый файл отдельно: если в wishes/fans.json уже есть daily[ДАТА] — шаг 4 пропусти; если в wishes/team.json уже есть daily[ДАТА] или в его calendar нет ключа ДАТА (не рабочий день) — шаг 5 пропусти; если в wishes/ng.json уже есть daily[ДАТА] или ДАТА не рабочий день (нет в calendar team.json) — шаг 5б пропусти. Если всё пропущено — задача сделана, заверши без изменений.
3. ПОДПИСЧИКИ — поводы. Найди через веб-поиск поводы ДАТЫ, но используй ТОЛЬКО те, что близки бренду: подарки и сюрпризы (день подарков, сюрпризов, объятий, комплиментов, доброты, благодарности и т.п.); поводы для радости и тёплые семейные праздники (день улыбки, день мамы/папы/бабушек и дедушек, день семьи, друзей, влюблённых, 8 Марта, 23 Февраля, первый снег, начало сезона); всё детское (день защиты детей, каникулы, школьные праздники, сказки и игры, день мороженого, конфет и сладостей); новогоднее и зимние праздники (подготовка к Новому году, Дед Мороз, ёлка, мандарины, Рождество, Старый Новый год). Остальные поводы (профессиональные дни, технологии, интернет, наука, спорт, памятные даты и т.п.) НЕ упоминай. Никогда не касайся политики, войн, трагедий, болезней, религиозных споров, скандалов, чужих брендов и знаменитостей. Если подходящего повода нет — пиши про сезон, день недели, уют, чай, заботу, подарки и маленькие радости.
4. Подписчикам (wishes/fans.json): добавь daily["ДАТА"] = массив из 12 новых фраз. Обращение на «ты», 1 предложение (иногда 2), до 110 символов, тепло, без пафоса и канцелярита, можно лёгкий юмор; если есть подходящий повод — 4–6 фраз про него, остальные — про сезон, подарки и добрые пожелания. Если фраза зависит от рода — нейтральная формулировка или «рад(а)». Без эмодзи и хэштегов. «Сегодня» = ДАТА. Проверь орфографию.
5. Команде (wishes/team.json): daily["ДАТА"] = ОБЪЕКТ с семью полями. Основной текст (перед цифрами): "record" — вчера лучший результат по заказам за месяц; "up" — вчера больше заказов, чем днём раньше; "steady" — примерно как раньше; "support" — спад или данных нет (поддержка без упрёков, без цифр, текст самодостаточный). Фраза после цифр (она же на картинке): "reaction_record", "reaction_up", "reaction_steady" — 1–2 предложения, до 150 символов: тёплая реакция на результат и пожелание на сегодня. Основные тексты: на «вы»/«команда»/«коллеги», 1–3 предложения, до 200 символов, цифр НЕ пиши. Понедельник — итоги за пятницу и выходные («прошлые дни») + настрой на неделю; пятница — спасибо за неделю и хороших выходных; последний рабочий день месяца — итоги месяца. Праздники подписчиков не тащи. Если calendar[ДАТА] посвящён празднику или событию — сохрани этот повод в основных текстах.
5б. Новогодняя рассылка (wishes/ng.json): daily["ДАТА"] = ОБЪЕКТ с теми же семью полями, тема — новогодний сезон и результаты новогодней коллекции (группа «НГ27_ВБ»): «рекорд сезона», рост новогодних продаж, стабильный темп сезона; образы — Дед Мороз, сани, ёлка, гирлянды, снег, подарки, мандарины, «каждый заказ — чьё-то праздничное утро». Тон бодрый, праздничный, без цифр, те же длины и правила для понедельника/пятницы.
6. Неповторимость: новые тексты не должны совпадать или быть почти одинаковыми ни с одной фразой в этих трёх файлах (включая поля внутри объектов). Проверь скриптом на Python (нормализованный текст и difflib ratio > 0.8) и замени похожие.
7. Сохрани JSON (UTF-8, ensure_ascii=False, indent=1 для team.json и ng.json; в fans.json вставляй блок текстом, не пересериализуй весь файл). Проверь json.load для всех трёх файлов и что `WISH_DATE=ДАТА DRY_RUN=1 python3 scripts/send_bitrix.py` и `WISH_DATE=ДАТА DRY_RUN=1 WISHES_FILE=wishes/ng.json python3 scripts/send_bitrix.py` отрабатывают без ошибок. Больше ничего не меняй.
8. Закоммить с сообщением «Свежие фразы на ДАТА» и сделай `git push origin main` (при отказе — `git pull --rebase origin main` и повтори до 4 раз).
9. Кратко перечисли повод дня и добавленные тексты.
```

## Задача 2 — «Рассылки в Битрикс24», каждый день в 10:00

```
Запусти утренние рассылки «Дари Сейчас» в Битрикс24. Работай в папке репозитория wallpapers (GitHub usmanovaalisa-maker/wallpapers).
1. Определи сегодняшнюю дату по Europe/Samara (ДАТА). Если сегодня суббота или воскресенье, или ДАТЫ нет в calendar файла wishes/team.json — ничего не запускай, это выходной.
2. Сделай `git fetch origin main`. Если в origin/main уже есть cards/ДАТА.jpg — bitrix-daily.yml не запускай (сегодня уже отправляли); если есть cards/ng-ДАТА.jpg — не запускай bitrix-ng.yml.
3. Остальное запусти через GitHub CLI:
   gh workflow run bitrix-daily.yml -R usmanovaalisa-maker/wallpapers --ref main -f dry_run=false
   gh workflow run bitrix-ng.yml -R usmanovaalisa-maker/wallpapers --ref main -f dry_run=false -f to_me=false
4. Через пару минут проверь `gh run list -R usmanovaalisa-maker/wallpapers --limit 4`, что запуски завершились успешно. Ничего в репозитории не меняй. Итог — одной-двумя строками.
```

## Если компьютер выключен

- Фразы на завтра не напишутся — тогда уйдут запасные тексты из календаря (ничего не сломается).
- Отправку в 10:00 подстрахует расписание GitHub Actions: оно запустит рассылку само, но иногда
  с опозданием на несколько часов. Повторной отправки не будет — скрипт проверяет, отправляли ли сегодня.
