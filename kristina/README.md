# Кристина — поздравительная карточка товара

Одностраничный мини-сайт в духе карточки маркетплейса. Сначала выглядит как
обычная карточка товара, а после нажатия «Оформить заказ» раскрывается
поздравление с днём рождения.

Чистые HTML, CSS и JavaScript: ни сборки, ни зависимостей, ни сервера.

## Что нужно положить перед публикацией

Код уже рассчитан на визуалы из архива `kristina-wb-visuals.zip`.
Скопируйте папку `assets/` из архива сюда, в `kristina/`, чтобы получилось так:

```
kristina/
├── index.html
├── styles.css
├── app.js
├── favicon.svg
├── README.md
└── assets/
    ├── slides/        01 02 03 04 05 06  (.jpg + .png)
    └── blocks/        07-reviews  08-finale  (.jpg + .png)
```

Страница подставляет `.jpg` — они легче и грузятся быстрее. Если рядом лежит
только `.png`, он подхватится автоматически, так что качественные версии можно
спокойно хранить в проекте. Если файла нет вообще, на его месте появится
аккуратная заглушка с именем недостающего файла — вёрстка не разъезжается.

Папку `sources/photos/` публиковать не нужно: она уже добавлена в `.gitignore`
корня репозитория. Исходные фотографии остаются только для будущих правок, для
сайта достаточно `assets/`.

## Публикация на GitHub Pages

1. Закоммитьте и запушьте папку `kristina/` (вместе с `assets/`) в репозиторий.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите
   **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save** и подождите пару минут.

Страница будет доступна по вложенному адресу:

```
https://<логин>.github.io/<репозиторий>/kristina/
```

Например: `https://usmanovaalisa-maker.github.io/wallpapers/kristina/`

Все пути в коде относительные, поэтому вложенный адрес работает без правок.
Сайт можно так же просто открыть из любой другой подпапки или локально.

## Локальная проверка

Откройте `index.html` двойным щелчком либо поднимите простой сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000/kristina/
```

## Что есть на странице

1. **Галерея** — шесть слайдов `01`–`06` в формате 3:4. Свайп пальцем,
   стрелки на компьютере, точки-индикаторы, счётчик `1 / 6`, управление
   клавишами ← →. Изображения показываются целиком (`object-fit: contain`),
   без обрезки.
2. **Карточка товара** — «Кристина», «Специалист по карточкам WB · Premium»,
   рейтинг `5,0`, артикул `KRISTINA-2026`, цена `БЕСЦЕННА`, остаток `1 шт.`
   Кнопка «Добавить в корзину» показывает сообщение
   «Этот товар уже работает в нашей команде».
3. **О товаре**, блок «С этим товаром покупают» (торт, подарок, отпуск) и
   **отзывы** с визуалом `assets/blocks/07-reviews`. Над отзывами стоит
   пометка, что они шуточные и не являются реальными отзывами покупателей.
4. **«Оформить заказ»** запускает последовательность
   «Оформляем заказ…» → «Проверяем остатки…» → финальный экран
   `assets/blocks/08-finale`. Экран закрывается крестиком, щелчком по фону
   или клавишей Esc, а кнопка внизу меняется на
   «Открыть поздравление снова».
5. **«Получить подарок»** под финальным изображением показывает фразу
   «Подарок ждёт тебя в реальной жизни :)».

## Оформление

Белый и светло-сиреневый фон, фиолетовые акценты, системные шрифты, спокойные
переходы. Без сердечек, лучиков и конфетти. Официальный логотип Wildberries не
используется; в подвале есть пометка, что страница шуточная и с Wildberries не
связана. Анимации уважают системную настройку «уменьшить движение».

## Проверено

Chromium через Playwright на ширинах 360, 390, 412 и 1280 px, а также в
альбомной ориентации: горизонтального скролла нет нигде, свайп и стрелки
переключают слайды, счётчик и точки синхронны, финальный экран целиком
помещается на экране телефона, открывается и закрывается повторно.
На компьютере карточка центрируется в колонке шириной 480 px.
