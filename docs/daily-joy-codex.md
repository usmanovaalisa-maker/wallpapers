# Повод для радости и символический рисунок

Ежедневно в 11:30 по Europe/Samara готовим тексты НА ЗАВТРА, включая выходные.
GitHub Actions самостоятельно собирает карточку с символическим рисунком по теме дня,
берёт реальные цифры из Google Sheets, вкладка «Свод по дням», и отправляет в существующий чат «НГ 2026-2027».
Генерировать, скачивать и загружать отдельные картинки не нужно.

Рабочая папка: `/Users/alisatitova/Documents/ChatGPT/Codex/wallpapers`.

1. Выполни `python3 scripts/daily_phrases.py start`. Команда обновляет чистую main без
   удаления незавершённой работы и показывает дату и тексты последних дней. Если остались
   материалы прошлого запуска, сначала проверь их и возобнови публикацию; не удаляй.
2. Найди веб-поиском подходящий повод для этой даты: подарки, сюрпризы, доброта, благодарность,
   семья, детство, сладости, уют и Новый год. Открой страницу и проверь дату.
   Не выдавай неофициальный праздник за официальный или всемирный. Политику, религиозные,
   памятные и профессиональные даты, трагедии, болезни, технологии, спорт, чужие бренды
   и знаменитостей не используй. Если повода нет — предложи маленькую радость дня:
   чайную паузу, тёплую записку близкому, семейную игру. Не называй её праздником.
3. Подготовь объект `ng` из восьми вариантов: `record`, `up`, `steady`, `support` —
   до 200 символов без цифр; `reaction_record`, `reaction_up`, `reaction_steady`,
   `reaction_support` — до 150. Обращение на «вы»/«команда»/«коллеги». Без упрёков,
   без выдуманных финансовых результатов. Пожелание свяжи с поводом, не повторяя мысль
   основного текста. Уровни record/up/steady/support определяются по общей сумме заказов ВБ + Озон:
   говори о сумме заказов, не называй её выручкой от продаж. Не повторяй последние семь дней. Учитывай день недели и уместный календарный повод.
4. Добавь `occasion` (до 160 символов), `occasion_title` (до 26) и `occasion_icon`:
   gift (подарок), heart (сердце), smile (улыбка), snowflake (снежинка), candy (конфета),
   family (семья), tree (ёлка), star (звезда), tea (чашка), cake (торт), toy (мишка),
   pancakes (оладушки). Это готовые векторные рисунки шаблона. Выбери один подходящий.
   Для подтверждённого праздника укажи `occasion_kind: "holiday"` и `occasion_sources`
   со списком проверенных URL. Для идеи маленькой радости — `occasion_kind: "small_joy"`
   и `occasion_sources: []`.
5. Сохрани `{ "date": "ГГГГ-ММ-ДД", "ng": { ... } }` в `.local/phrases.json`.
   Выполни `python3 scripts/daily_phrases.py add .local/phrases.json` и исправь ошибки.
6. Проверь карточки `python3 scripts/daily_phrases.py preview`.
   Для локальной отрисовки получи Node/пакеты из `load_workspace_dependencies` и установи
   `CARD_NODE_RUNTIME` (полный путь к Node) и `NODE_PATH` (папка Node-пакетов).
   На GitHub используется уже установленный Python Playwright. Просмотри четыре результата
   в `.local/previews/`: текст не обрезан, дата и символ верны. В репозиторий эти превью не загружай.
7. Выполни `python3 scripts/daily_phrases.py publish`. Публикуются только `wishes/ng.json`
   и отметка запуска; картинку GitHub рисует сам. Не запускай Run workflow и не отправляй
   дополнительные сообщения в Битрикс24.

Если сохранённый доступ Git не работает, можно загрузить только текстовый `ng.json` через
уже авторизованный Chrome. Выполни `python3 scripts/daily_phrases.py bundle`, затем открой
`https://github.com/usmanovaalisa-maker/wallpapers/upload/main/wishes` → Choose your files.
В macOS нажми Cmd+Shift+G, дождись поля полного пути, заполни его через setValue полным
путём `.local/web-upload/ng.json`. Проверь выбранное имя файла, нажми «Открыть», дождись
загрузки. Проверь целевую папку wishes и что добавлен ТОЛЬКО ng.json; Commit directly to main.
После публикации сделай fetch и сверь `git show origin/main:wishes/ng.json` с локальным файлом.
Если результат загрузки неясен — сначала проверяй origin/main, не публикуй повторно вслепую.
Не создавай токены и не меняй права доступа. Если нужен вход — сохрани подготовленное и сообщи пользователю.

После подтверждённой веб-публикации сохрани локальные коммиты в отдельной ветке codex/,
убедись, что весь комплект уже есть в origin/main, и синхронизируй рабочую main.
Не удаляй неподтверждённые материалы. Если старый Claude ещё запускается, не создавай дубли
на одну дату: готовый комплект пропускается. Подготовка новых поводов требует работающего Codex
на компьютере; сама отправка GitHub работает отдельно.

В этот чат пиши только о сбое подготовки/публикации или необходимом действии пользователя.
При обычном успешном запуске оставайся тихим. Финансовые расчёты, получателей и секреты не меняй.

## Источник цифр с 04.11.2026

Данные берутся непосредственно из выбранной таблицы «Новый год 2027 — план, факт, динамика
и сравнение с НГ 2026», вкладка «Свод по дням» (gid 1887142559), сезон «НГ 2027».
Адрес задаётся защищённым секретом GitHub `NG_SHEETS_URL`; не вставляй его в публичный код.
Режим новогоднего workflow: `RESULTS_SOURCE=google_sheet`.

В сообщении три блока в порядке ВБ → Озон → Итого: сумма заказов (₽), продажи (₽), выкуп (%)
и прибыль (₽) с точной подписью из таблицы: «Чистая прибыль» либо «Прибыль без опер. расходов».
После прибыли в скобках показывается «маржинальность: …%» из колонок N/O/P «Чистая маржа, %»
для соответствующей площадки и итога. Значения берутся из таблицы, не вычисляются из округлённых сумм
и не усредняются по площадкам. Отрицательные значения и ноль сохраняются; пустая ячейка — «нет данных».
Начиная с 12.11.2026 таблица содержит чистую прибыль. Её не называем прибылью без операционных расходов.
Заказы в штуках не выводятся: источник даёт денежную сумму.
Общий выкуп берётся из колонки Итого, не усредняется по площадкам. Убыток Озона и нулевая прибыль
сохраняются. Накопительная сумма заказов считается только за фактический полный период таблицы.
Уровень пожелания выбирается по общей сумме заказов к предыдущему дню.

Если за вчера нет строки, метка обновления отстаёт, выбран другой сезон, появились ошибки формул
или итог не сходится с площадками, сообщение откладывается. Подменять источник на TrueStats нельзя.
Финансовые значения не коммитятся и не выводятся в публичный лог; символическая карточка содержит только пожелание.
